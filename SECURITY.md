# Security Policy

## Scope

This repository is **public-facing only**. It contains the static source for [fabiomassanga.com](https://fabiomassanga.com) and repository governance files. It must not contain production secrets, private keys, credentials, internal architecture specifications, or operational runbooks.

## Supported versions

| Component | Supported |
|-----------|-----------|
| Public website (`fabiomassanga.com`) | Current `main` branch deployment |
| Historical tags | Best effort |

## Reporting a vulnerability

If you believe you have found a security issue related to this public site or repository:

1. **Do not** open a public GitHub issue with exploit details, credentials, or internal system information.  
2. Email **support@biu-gholdings.org** with a clear description and steps to reproduce (if applicable).  
3. Allow reasonable time for review before public disclosure.

We appreciate responsible disclosure.

## What does not belong in this repo

- API keys, tokens, or passwords  
- Private keys, certificates, or wallet material  
- Production deployment credentials  
- Internal validator, treasury, liquidity, or node topology documentation  
- Investor, legal, financial model, or cap table materials  

If such material is discovered in the public history, report it privately so it can be addressed appropriately.

## Public repository expectation

Contributors and maintainers should assume all commits are public and permanent. Use a separate **private** repository for anything that is not appropriate for public institutional disclosure.
