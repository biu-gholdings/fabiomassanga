Biography

Fábio G. Massanga is the founder and CEO of CubeShackles, an Angola-first financial infrastructure company focused on identity, payments, compliance, and transaction visibility.

His work is centered on the belief that Africa does not have a financial access problem alone — it has an infrastructure alignment problem.

CubeShackles is being built from local economic reality: informal markets, fragmented identity systems, underdeveloped financial rails, and the need for infrastructure that can be read by institutions and regulators.

System Guarantees

1. Identity-Linked Transactions

All transactions are linked to verified identities through national or institutional identifiers. This ensures:

  • Auditability
  • Compliance readiness
  • Reduced fraud surface

2. Deterministic Settlement Visibility

Transactions are visible in real-time with:

  • Pending state
  • Confirmed state
  • Settlement status

No hidden flows.

3. Offline-Compatible Execution

The system supports:

  • Delayed synchronization
  • Offline transaction capture
  • Eventual consistency with audit trails

4. Institutional Observability

Regulators and institutions can access:

  • Transaction flows
  • Liquidity movement
  • Identity-linked activity

Without interfering with system operation.

5. Controlled Economic Design

Utility is tied to:

  • System usage
  • Transaction activity

Not speculative behavior.

6. Bounded System Exposure (Pilot Phase)

  • No public token exposure
  • Closed transaction environment
  • Controlled participant onboarding

7. Immutable Transaction Record

Once validated:

  • Transactions cannot be altered
  • Full traceability is preserved

Transfer Lifecycle

1. Initiation

User initiates transaction via:

  • Phone number
  • Identity-linked account

2. Validation Layer

System checks:

  • Identity validity
  • Balance availability
  • Transaction rules

3. Encoding into Cube

Transaction is encoded as a "Cube":

  • Contains sender, receiver, amount, timestamp

4. Shackle Linking

Cube is attached to previous state via:

  • Cryptographic linkage
  • Sequential integrity

5. Validator Processing

Validators:

  • Confirm validity
  • Broadcast state update

6. State Update

Transaction enters:

  • Pending -> Confirmed -> Settled

7. Institutional Visibility

Data becomes accessible to:

  • Regulators
  • Authorized institutions

8. Final Settlement

Funds are recognized as:

  • Completed
  • Auditable
  • Immutable

Wedge Lock

Defined Wedge

Phone-number-based, identity-linked transactions for informal markets.

Target Users

  • Informal merchants
  • Individuals without structured banking access
  • Small local businesses

Core Capabilities

  • Send/receive via phone number
  • Identity-linked transaction history
  • Real-time transaction visibility
  • Basic settlement tracking

What is NOT included

  • No DeFi
  • No speculation layers
  • No public token trading
  • No multi-country expansion

Success Criteria

  • Functional transaction loop (send -> confirm -> settle)
  • 100-1,000 real user transactions
  • Institutional visibility demo ready
  • Regulator-readable data output

Lock Condition

No expansion until:

  • Wedge is fully operational
  • Transactions are stable
  • Data is verifiable

Failure Condition

  • Adding complexity before validation
  • Building features not used in wedge
  • Shifting focus away from core transaction loop

Regulatory & Institutional Alignment

Designed for structured interaction with Angola’s financial, capital markets, fiscal, and taxation authorities.

CubeShackles is being designed to operate inside institutional boundaries, not around them.

The objective is to build infrastructure that can be observed, audited, and understood by institutions responsible for monetary policy, capital markets, taxation, public finance, and economic supervision.

Banco Nacional de Angola

Monetary control, settlement oversight, and systemic risk alignment.

Comissão do Mercado de Capitais

Digital asset classification and capital markets interoperability.

Ministério das Finanças

Fiscal reporting, treasury flows, and public finance coordination.

Administração Geral Tributária

Tax compliance, transaction traceability, and revenue capture.
