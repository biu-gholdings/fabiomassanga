Biography

Fábio G. Massanga is the founder and CEO of CubeShackles, an Angola-first financial infrastructure company focused on identity, payments, compliance, and transaction visibility.

His work is centered on the belief that Africa does not have a financial access problem alone — it has an infrastructure alignment problem.

CubeShackles is being built from local economic reality: informal markets, fragmented identity systems, underdeveloped financial rails, and the need for infrastructure that can be read by institutions and regulators.

Angola First

Angola is the highest-leverage entry point: high transaction activity, low infrastructure coherence, and clear institutional need.

The timing is now because identity, payments, and compliance infrastructure can be coordinated into one operating layer instead of fragmented tools.

I am executing this directly through CubeShackles with a constrained wedge, measurable transaction flow, and regulator-readable outputs.

System Guarantees

1. Identity-Linked Transactions

All transactions are linked to verified identities through national or institutional identifiers. This ensures:

  • Auditability
  • Compliance readiness
  • Reduced fraud surface

2. Deterministic Settlement Visibility

Transactions are visible in real-time with:

  • Pending state
  • Confirmed state
  • Settlement status

No hidden flows.

3. Offline-Compatible Execution

The system supports:

  • Delayed synchronization
  • Offline transaction capture
  • Eventual consistency with audit trails

4. Institutional Observability

Regulators and institutions can access:

  • Transaction flows
  • Liquidity movement
  • Identity-linked activity

Without interfering with system operation.

5. Controlled Economic Design

Utility is tied to:

  • System usage
  • Transaction activity

Not speculative behavior.

6. Bounded System Exposure (Pilot Phase)

  • No public token exposure
  • Closed transaction environment
  • Controlled participant onboarding

7. Immutable Transaction Record

Once validated:

  • Transactions cannot be altered
  • Full traceability is preserved
