Biography

Fábio G. Massanga is the founder of CubeShackles, Managing Member of Biu-g Holdings LLC, and trustee of BIU.G Academy. His work focuses on sovereign financial infrastructure for Africa, beginning with Angola.

Through CubeShackles, he is building an Angola-first infrastructure layer for identity-linked transactions, payment visibility, informal market digitization, institutional reporting, and regulator-readable financial systems.

His thesis is that Africa’s financial access problem is not only a banking issue. It is an infrastructure coordination problem across identity, payments, taxation, compliance, settlement, education, and public trust.

His current work is centered on a controlled wedge: phone-number-based transactions, identity-linked flows, informal merchant onboarding, and infrastructure that can be observed, audited, and understood by institutions.

CubeShackles — System Overview

CubeShackles is a financial infrastructure platform designed to integrate identity, payments, and economic data into a unified and auditable system.

The architecture is structured around four core layers:

Identity Layer

All activity is linked to verified user identities, enabling traceability, compliance, and structured participation across both informal and formal sectors.

Transaction Layer

Users can initiate and receive transactions through simplified interfaces, including phone-number-based interactions, designed for accessibility and low-friction adoption.

Validation Layer

Transactions are processed and confirmed through a controlled validation mechanism that ensures integrity, sequencing, and consistency of system state.

Visibility Layer

Authorized institutions can access structured views of system activity, including transaction flows, settlement states, and identity-linked behavior, supporting oversight and coordination.

The system is designed to operate within a controlled environment during initial deployment, with clearly defined boundaries, monitored activity, and no public exposure.

This architecture enables a coordinated financial framework that supports inclusion, transparency, and institutional alignment without compromising operational control.

System Guarantees

1. Identity-Linked Transactions

All transactions are linked to verified identities through national or institutional identifiers. This ensures:

  • Auditability
  • Compliance readiness
  • Reduced fraud surface

2. Deterministic Settlement Visibility

Transactions are visible in real-time with:

  • Pending state
  • Confirmed state
  • Settlement status

No hidden flows.

3. Offline-Compatible Execution

The system supports:

  • Delayed synchronization
  • Offline transaction capture
  • Eventual consistency with audit trails

4. Institutional Observability

Regulators and institutions can access:

  • Transaction flows
  • Liquidity movement
  • Identity-linked activity

Without interfering with system operation.

5. Controlled Economic Design

Utility is tied to:

  • System usage
  • Transaction activity

Not speculative behavior.

6. Bounded System Exposure (Pilot Phase)

  • No public token exposure
  • Closed transaction environment
  • Controlled participant onboarding

7. Immutable Transaction Record

Once validated:

  • Transactions cannot be altered
  • Full traceability is preserved
