Biography

Fábio Massanga is the founder and CEO of CubeShackles, building financial infrastructure for Africa, starting with Angola.

His work focuses on digital identity, regulated payment rails, informal market digitization, and sovereign financial infrastructure designed around local realities.

Core Ideas

  • Digital identity is the control layer of financial systems.
  • Informal markets are not broken — they are unstructured.
  • Infrastructure must be built natively, not imported.
  • Regulators must be co-designers, not obstacles.

The Wedge

CubeShackles does not start by trying to replace the entire financial system. It starts with the transaction layer where informal economic activity already happens.

  • Phone-number-based transactions
  • Identity-linked financial flows
  • Informal merchant onboarding
  • Real-time transaction validation
  • Regulator-readable activity trails

From there, the system expands into merchant networks, institutional integrations, and national-scale infrastructure.

CubeCoin

CubeCoin is the proposed native economic layer for CubeShackles: a coordination asset designed around validation, infrastructure access, and ecosystem participation.

It is not positioned as a speculative promise. It is designed as part of the infrastructure economics behind identity-linked transactions, network validation, and regulated ecosystem usage.

CubeShackles

CubeShackles is an Angola-first financial infrastructure system designed to connect identity, payments, compliance, and transaction visibility into one operating layer.

The system is being built for real-world financial activity: informal markets, merchants, institutions, regulators, and local currency transaction flows.

BIU.G Academy

BIU.G Academy is the education layer for financial literacy, digital infrastructure adoption, developer training, and public understanding of CubeShackles.

Its role is to help users, developers, merchants, and institutions understand and adopt new financial infrastructure with discipline.

Thesis

Africa does not have a financial access problem. It has an infrastructure alignment problem.

Financial activity across Angola is already happening — informally, continuously, and at scale. The issue is not lack of activity. The issue is lack of infrastructure that can structure, verify, and route that activity.

The next generation of financial infrastructure will not be imported. It must be built natively around local currencies, real user behavior, identity systems, and regulatory visibility.

Proof of Work

Active development across CubeShackles core systems, node infrastructure, transaction validation layers, and developer tooling.

  • Multiple core repositories rebuilt and structured for execution
  • Validator, explorer, and node API components under active development
  • Transaction flows being simulated and documented
  • Architecture designed around identity, validation, and auditability

System Design

The system integrates identity, payments, compliance, and transaction visibility into a unified financial layer.

Built on a distributed structure of cubes and shackles, it enables transaction flow, delayed settlement, and institutional-grade auditability across regions.

Why This Exists

This is not theoretical.

CubeShackles comes from direct observation of informal markets, fragmented identity systems, underdeveloped transaction infrastructure, and the gap between how people already trade and how formal systems recognize value.

The system is being built from ground reality — not imported assumptions.
